# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email **mayankpathakmp@gmail.com** with:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
3. You will receive an acknowledgment within 48 hours.
4. A fix will be prioritized and released as soon as possible.

## Security Best Practices

- This application does not collect or store user data server-side.
- The contact form generates a `mailto:` link; no data is transmitted to the server.
- Dependencies are kept up to date and audited regularly via `npm audit`.
